## 设计原则

1. **静态优先**：不在运行时依赖服务器，搜索、筛选和主题切换全部在浏览器完成。
2. **数据可降级**：GitHub 同步失败不能阻断构建，缓存是构建的一部分。
3. **分层清晰**：领域规则不依赖 Astro、浏览器或 GitHub，方便测试与替换。
4. **可访问**：键盘、焦点、屏幕阅读器与减少动效是默认要求，不是补丁。
5. **可维护**：数据只有一个来源，生成文件有明确边界，CI 对所有提交执行同一套检查。
